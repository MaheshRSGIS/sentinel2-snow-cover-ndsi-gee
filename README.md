SENTINEL-2 SNOW COVER MAPPING USING NDSI  

OVERVIEW Of PROJECT:
This project demonstrates snow-cover mapping using Sentinel-2 satellite imagery and the Normalized Difference Snow Index (NDSI) in Google Earth Engine.

OBJECTIVE OF THE PROJECT:
To identify and estimate snow-covered area using Sentinel-2 multispectral imagery and NDSI-based thresholding.

DATA:
1. Sentinel-2 Surface Reflectance Harmonized
2. Google Earth Engine
3. Study period: September–October 2017
4. Green band: B3
5. SWIR band: B11

METHODOLOGY:
1. Sentinel-2 image collection filtering
2. Cloud-based image filtering
3. NDSI calculation
4. Median composite generation
5. NDSI histogram analysis
6. Threshold-based snow classification
7. Snow-covered area calculation
8. Raster export

TOOLS: Google Earth Engine, JavaScript, Sentinel-2, Remote Sensing, GIS
